Your cameras, recorded on your own disk.

RecoraCam is a self-hosted video recorder for IP cameras. Set a weekly schedule, watch live, scrub through a 24-hour timeline and export clips from any browser. No cloud, no account, no subscription.

Get started View on GitHub

Free and open source under the LGPL v3. Runs on Windows and Linux with Python and FFmpeg.

  • Your footage stays on your disk.Recordings, settings and the database stay on your computer. There is no account to create.
  • Plain files on a plain disk.Footage is saved as camera, day and short segments that any video player can open.
  • Free software.Released under the LGPL v3. Read it, change it, run it as long as you like.

Everything between the camera and the clip

Add a camera, tell it when to record, and find any moment later. The whole thing runs in your browser.

Add a camera and test it before you save

Enter a name and the stream address. Test connection opens the stream for a few seconds and reports the codec, size and frame rate, or tells you what is wrong: a bad password, a missing stream path, an unreachable camera.

  • Any address FFmpeg can read: RTSP, RTMP, HTTP, UDP, SRT and more
  • An optional lower-resolution substream for the live tiles
  • Typical addresses for Hikvision, Dahua, Reolink and Tapo are listed in the quick start

Record when you want, with a weekly plan

Drag across a grid of the week in 15-minute steps, or start from a quick fill: all day, business hours, nights or weekends. Plan several cameras at once, or copy another camera's plan.

  • Recording is a straight copy of the stream, so quality is exactly what the camera sends and CPU use stays close to zero
  • Footage is cut into short segments, 10 seconds by default
  • Recording starts at once if the current time is inside the plan

See at a glance that everything is recording

The camera wall shows each camera's status and a recent picture, with CPU, memory, disk and network beside it. Click a tile to watch live.

  • A supervisor restarts a failed recorder with growing delays, so a dead camera does not cause a restart storm
  • A check every 60 seconds restarts any camera that should be recording but is not, after an app restart, a network drop or a crashed FFmpeg
  • Live video is optional and uses go2rtc, with very low delay

Scrub through a whole day

Pick a camera and a day on the calendar, then move along a 24-hour timeline. Zoom to 6 hours or 1 hour, jump between recorded sessions, and play straight across gaps and into the next day.

  • Keyboard shortcuts, playback speed and a 12 or 24-hour clock
  • Browsers play H.264 everywhere, but H.265 only in some. For H.265 cameras, switch the camera to H.264

Export exactly the clip you need

Mark an in point and an out point on the timeline, queue several clips and download them as MP4 files.

  • H.264 cameras are cut without re-encoding, so exports take seconds and lose no quality
  • Other codecs, such as MPEG-2, are converted on an NVIDIA GPU if there is one, otherwise on the CPU
  • Prepared files are removed after a time you choose

Keeps the disk from filling up

When the recording disk passes a limit (85 percent by default), RecoraCam deletes the oldest days first, across all cameras, at the times you choose.

  • Choose the recording folder with a folder picker
  • Set the segment length, playback defaults and live-view refresh
  • Day-to-day settings live in the browser, with no config files to edit

Up and running in a few minutes

RecoraCam needs no database server and no build step. Install two things, clone the project and start it.

You need Python 3.10 or newer, FFmpeg and one or more IP cameras that stream RTSP, which nearly all do.

winget install Gyan.FFmpeg
git clone https://github.com/YOUR-USERNAME/recoracam-nvr.git
cd recoracam-nvr

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python scripts/get_binaries.py   # optional: live view (go2rtc)
python app.py                    # or double-click run_windows.bat
sudo apt install ffmpeg          # macOS: brew install ffmpeg
git clone https://github.com/YOUR-USERNAME/recoracam-nvr.git
cd recoracam-nvr

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python scripts/get_binaries.py   # optional: live view (go2rtc)
python app.py

Open http://localhost:5000. The database and the log folder are created on the first start. Stop with Ctrl+C.

RecoraCam has no login yet. Anyone who can reach its port can watch, download and delete recordings. Run it on a trusted network, and do not expose ports 5000 or 1984 to the internet. For remote viewing, use a VPN.

Add your first camera

  1. Add itOpen Cameras, press + Add, then enter a name and the stream address.
  2. Test itPress Test connection. You get the codec, size and frame rate, or the reason it failed.
  3. Schedule itOpen Schedules, tick the camera, press 24 / 7 or drag the hours you want, and save.

No camera yet? Run the demo.

Demo mode starts simulated RTSP cameras that behave like real ones. They appear on the Cameras page and record around the clock, so you can try every page in two minutes.

  • It has its own database and recordings in dev/demo_data, so your real cameras and footage are never touched
  • A yellow DEMO badge shows in the top bar
  • Start the app without --demo to go back to normal
python dev/setup_demo.py   # once: downloads MediaMTX and go2rtc,
                           # makes four sample videos with FFmpeg
python app.py --demo       # Windows: run_demo_windows.bat

How it works

One FFmpeg process per camera copies the stream to disk. Everything else reads that folder.

  1. IP camerasRTSP, RTMP, HTTP, UDP or SRT streams
  2. FFmpegone process per camera, copying the stream without re-encoding
  3. Recording foldercamera, day, then short segment files
  4. Flask appplayback, export, settings and a JSON API
  5. Your browsera single-page app that plays footage with video.js

The folder is the index. The start time and length of each segment are in its file name, so there is no recordings database that can get out of step with the disk.

APScheduler starts and stops each recorder from its weekly plan, and a supervisor restarts whatever fails. go2rtc is optional: it connects to each camera once and shares the stream with every browser that watches live. RecoraCam is built with Python, Flask, APScheduler, SQLite, FFmpeg and video.js, and its front end is plain JavaScript with no build step.

What to know before you install

RecoraCam is young. These are its limits today and the ideas for later.

Today

  • No login or HTTPS yet, so keep it on a trusted network or behind a VPN
  • Camera passwords are part of the stream address, so they are stored as plain text in the local database. Use a view-only camera user
  • H.265 cameras record fine, but most browsers cannot play them back
  • It does not detect people or vehicles
  • There is no Docker image yet

Ideas, not promises

  • User accounts, login and HTTPS
  • A Docker image and a docker compose file
  • Automated tests and CI
  • Motion and event markers on the timeline
  • Converting H.265 to H.264 on demand for browser playback
  • Search by object or vehicle, and clip download by query

Questions

Which cameras work?

Any camera or encoder that gives you a stream FFmpeg can read. Nearly all IP cameras do, usually over RTSP. Press Test connection on the Cameras page to check one before you save it.

Do I need a GPU or a powerful computer?

No. Recording copies the stream instead of re-encoding it, so CPU use stays close to zero. An NVIDIA GPU is used only when you export footage from a camera that does not send H.264, and without one the CPU does that job.

How much disk space do I need?

Disk use is the camera's bit rate multiplied by time. You can find the bit rate on the camera's own web page.

Bit ratePer day30 days
1 Mbit/s11 GB324 GB
2 Mbit/s21.6 GB648 GB
4 Mbit/s43 GB1.3 TB
8 Mbit/s86 GB2.6 TB

Set the disk limit in Settings below what you can spare, and RecoraCam removes the oldest days when it is passed.

Does it work without internet?

Recording, schedules, playback and export need only Python and FFmpeg on your own network. Live view needs go2rtc, which scripts/get_binaries.py downloads once. The application's pages load two fonts from Google Fonts, so for a fully offline setup host those fonts locally.

Can I watch from outside my home?

Not safely without extra steps, because there is no login yet. Use a VPN such as WireGuard or Tailscale, or put a reverse proxy with HTTPS and authentication in front of it. Never open ports 5000 or 1984 to the internet.

Recording works, but playback is black. Why?

The camera is probably sending H.265 (HEVC), which most browsers cannot play. Switch the camera to H.264. The substream is often H.264 already, and downloaded MP4 files still play in VLC.

What does it cost, and what is the licence?

Nothing. RecoraCam is free software under the GNU Lesser General Public License, version 3. The full text is in the repository.
