# Demo mode (optional)

This folder holds a **camera simulator** so RecoraCam can be tried, filmed or developed without any camera.
It is **off by default**: a normal start never touches it, and none of its files are used for real cameras.

```
python dev/setup_demo.py      # once: downloads MediaMTX + go2rtc, generates 4 sample videos
python app.py --demo          # start the demo (Windows: run_demo_windows.bat)
```

Open http://localhost:5000 - the top bar shows a yellow **DEMO** badge.

## What the demo does

* Four simulated cameras - **Entrance, Lobby, Parking, Warehouse** - stream looping test videos
  as RTSP (`rtsp://127.0.0.1:8654/<name>`), exactly like real IP cameras do.
* They are added to the Cameras page and **record 24/7**, so the Playback and Download pages have footage after a few minutes.
* It has **its own database and recordings** in `dev/demo_data/`. Your real cameras, schedules and recordings
  are never read, changed or mixed with it.
* Everything it starts (the simulator, go2rtc) is stopped when you press Ctrl+C.

The sample videos are test patterns generated by FFmpeg (no real footage, nothing copyrighted, nothing large in git).
To use your own footage, copy `.mp4` / `.mkv` / `.mov` / `.avi` / `.ts` files into `dev/samples/`:
every file becomes one more camera at the next demo start.

## Switching it on and off

| I want to... | Do this |
|---|---|
| start the demo | `python app.py --demo` &nbsp;or&nbsp; set `RECORACAM_DEMO=1` &nbsp;or&nbsp; `run_demo_windows.bat` |
| go back to my real cameras | stop the app (Ctrl+C) and start it **without** `--demo` (`python app.py`, `run_windows.bat`) |
| start the demo from scratch | `python dev/setup_demo.py --reset` (deletes `dev/demo_data/`: demo database + recordings) |
| remove the demo completely | `python dev/setup_demo.py --clean` (also deletes the downloaded MediaMTX and the sample videos) |
| remove the demo from the code | delete the `dev/` folder and `run_demo_windows.bat`; nothing else needs it (the `--demo` code path in `app.py` is only taken when you ask for it) |

Run only one RecoraCam at a time (the real one **or** the demo): both use port 5000. To run both, give one of them
another port with `RECORACAM_PORT=5001`.

## Files

| File | Purpose |
|------|---------|
| `setup_demo.py` | one-time preparation, `--reset`, `--clean` |
| `demo_stack.py` | what `--demo` adds at start: simulator, camera list, 24/7 schedules |
| `fake_cameras.py` | the simulator: MediaMTX + one looping FFmpeg per video. Can also run alone (`python dev/fake_cameras.py`) to try the URLs in VLC |
| `MEDIAMTX_LICENSE` | licence of MediaMTX (MIT), the RTSP server that is downloaded into `bin/` |
| `bin/`, `samples/`, `demo_data/` | created on demand, git-ignored |

## Simulator settings (environment variables, optional)

| Variable | Default | Meaning |
|----------|---------|---------|
| `TEST_RTSP_PORT` | `8654` | RTSP port of the simulator (kept apart from go2rtc's 8554) |
| `TEST_REENCODE` | - | `1` = convert videos to H.264 instead of copying them (for files that do not stream well) |
| `FFMPEG` | `ffmpeg` | full path of ffmpeg if it is not on the PATH |

## Troubleshooting

* **"MediaMTX not found" or "no video files found"** - run `python dev/setup_demo.py` first.
* **"port 8654 is already in use"** - an old simulator is still running; end the `mediamtx` process or set `TEST_RTSP_PORT`.
* **The demo opens but has no cameras** - the simulator could not start; read the first lines of the console.
* **No live picture** - go2rtc is missing: `python scripts/get_binaries.py`.
