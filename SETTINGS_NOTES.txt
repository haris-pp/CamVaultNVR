If you merge app.py by hand, these are the only edits:
 1. next to "from daily_jobs import setup_daily_jobs" add:
        import daily_jobs
        import settings_api
 2. delete the old  @app.route("/api/settings", methods=["GET","POST"])  function (api_settings)
 3. right after set_setting(...) add:
        settings_api.init(app, get_setting, set_setting, scheduler, daily_jobs, DB)

No database change and no new packages. New settings are stored in the existing settings table
and fall back to their defaults until you save them.
